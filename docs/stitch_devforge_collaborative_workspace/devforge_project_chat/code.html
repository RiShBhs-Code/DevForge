Good catch, Sarah. I was thinking something along the lines of a Mutex for the refresh block. Here is a quick prototype of how that might look in Go:

auth_service.go 

var refreshMutex sync.Mutex

func (s *AuthService) RefreshToken(ctx context.Context, oldToken string) (string, error) {
    refreshMutex.Lock()
    defer refreshMutex.Unlock()

    // Check if token was already refreshed by another concurrent request
    if s.cache.Has(oldToken) {
        return s.cache.Get(oldToken), nil
    }

    // ... proceed with DB call and generation ...
}
